# Vaibhav Chahar

Vaibhav Chahar · Physics PhD candidate (lattice QCD and machine learning) · Warsaw. I build data pipelines, forecasting models and trading systems.

- [DK1 price forecasting](https://github.com/VChahar1/dk1-probabilistic-price-forecasting): day-ahead electricity forecasts with weather inputs, probabilistic models and audited saved results.
- [C++ limit order book](https://github.com/VChahar1/cpp-lob): price-time matching, cancellations, modifications and a generated-flow benchmark.
- [Market-risk engine](https://github.com/VChahar1/market-risk-var-engine): portfolio VaR, Expected Shortfall and backtests that expose calibration limits.
- [Pairs-trading study](https://github.com/VChahar1/pairs-trading): cointegration and Kalman filtering, with an honest negative result after costs.
- [Indian option data and pricing](https://github.com/VChahar1/Indian-Option-price-predictor): NSE collection, volatility surfaces and pricing checks; forecast accuracy remains unverified.
- [Ising autoregressive networks](https://github.com/VChahar1/gated-pixelcnn-ising-wegner): lattice-sampling research code with CPU numerical checks and GPU validation still pending.
- [Implied-volatility solver](https://github.com/VChahar1/implied-vol-solver): Newton and Brent inversion with numerical round-trip tests.

The linked studies include their methods, reproducibility instructions and limitations. Model experiments and saved backtests are presented with the checks that support them.
